# BetterBUCT v0.2.29

发布日期：2026-10-17

## 更新内容

- 适配学校新版 SId 统一身份认证入口 `sidportal.buct.edu.cn`，并保留 JWGLXT 服务回调。
- Android 校园登录白名单加入新认证域和 DNS 回退地址。
- Android 认证页可自动选择“用户名密码”方式后填写已保存凭据。
- 修复新版 SId 登录页被误判为已登录的问题，并更新登录页解析回归测试。

## 验证边界

- Node 自动化测试覆盖认证 URL、登录页识别和移动登录流程。
- Release APK 需通过包名、版本号、签名和 SHA-256 检查后发布。
- 自动化构建和 APK 签名检查不替代真实设备上的校园账号登录验收。
