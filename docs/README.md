## 📝 文档维护

### 更新规范

1. **版本发布时**必须更新:
   - README.md 的版本号和下载链接
   - PROGRESS.md 的时间戳和验收记录
   - RELEASE.md 的当前版本信息

2. **功能变更时**必须更新:
   - PROGRESS.md 的功能列表
   - ARCHITECTURE.md 的相关设计说明
   - README.md 的功能特性

3. **保持同步**:
   - 文档中的版本号、API、配置应与代码一致
   - 过时内容及时删除或标记

### 风格指南

- 使用中文撰写，保持专业和友好的语气
- 代码、命令、路径保持原样（不翻译）
- 使用 Markdown 标准格式
- 添加适当的标题层级和导航链接
- 重要提示使用引用块或加粗
