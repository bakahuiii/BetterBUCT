# 行为准则

## 我们的承诺

为了营造一个开放和友好的环境，我们作为贡献者和维护者承诺：让参与 BetterBUCT 项目和社区的每个人都能获得无骚扰的体验，无论年龄、体型、残疾、民族、性别特征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性取向如何。

---

## 我们的标准

### 有助于创造积极环境的行为包括：

✅ **尊重和包容**
- 使用友好和包容的语言
- 尊重不同的观点和经验
- 接受建设性的批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

✅ **专业和建设性**
- 针对代码、设计和事实提出具体意见，不攻击参与者本人
- 提供清晰、有建设性的反馈
- 承认他人的贡献和努力
- 在讨论中保持专业和冷静

✅ **协作和支持**
- 帮助新贡献者融入社区
- 分享知识和经验
- 鼓励和支持他人
- 积极解决冲突

### 不可接受的行为包括：

❌ **骚扰和攻击**
- 使用性化的语言或意象
- 人身攻击、侮辱或贬低性评论
- 公开或私下的骚扰
- 挑衅、恶意或人身攻击性的行为

❌ **歧视和不尊重**
- 基于个人特征的歧视性言论或行为
- 种族主义、性别歧视或其他歧视性评论
- 故意冒犯或排斥他人
- 嘲笑或贬低他人的背景或能力

❌ **隐私侵犯**
- 未经许可发布他人的个人信息（如学号、密码、联系方式）
- 分享他人的私密对话或敏感信息
- 泄露他人的校园数据或账号信息

❌ **恶意行为**
- 故意破坏项目或社区
- 发布恶意代码或安全漏洞
- 滥用 Issue、PR 或其他功能进行刷屏或骚扰
- 利用项目资源进行与项目无关的活动

❌ **其他不当行为**
- 在项目空间中从事不当的政治或宗教宣传
- 发布垃圾信息或广告
- 其他在专业环境中被合理认为不适当的行为

---

## 适用范围

本行为准则适用于以下所有项目空间：

- GitHub 仓库（代码、Issue、PR、讨论）
- 项目文档和 Wiki
- 提交的代码和文档内容
- 项目相关的公开或私下交流
- 代表项目参与的公开活动

本行为准则也适用于个人在公共空间代表项目或社区时的行为。代表项目或社区的示例包括：使用官方项目电子邮件地址、通过官方社交媒体账号发布内容，或在在线或离线活动中担任指定代表。

---

## 维护者的责任

项目维护者有责任：

1. **澄清标准**
   - 明确可接受行为的标准
   - 解答关于行为准则的疑问

2. **执行准则**
   - 对违反行为准则的行为采取适当和公平的纠正措施
   - 有权利和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、Issue 和其他贡献

3. **保护社区**
   - 暂时或永久禁止任何行为被认为不当、威胁、冒犯或有害的贡献者
   - 保护报告者的隐私和安全

4. **透明处理**
   - 解释处理决定的原因（在适当的情况下）
   - 给予改正的机会（视情况而定）

## 执行

### 报告不当行为

如果你遇到或目击了违反行为准则的行为，请通过以下方式报告：

#### 方式一：GitHub Issues（公开，适用于明显违规）

如果是明显的违规行为（如垃圾信息、明显的骚扰），可以：
- 在相关 Issue 或 PR 中 @ 提及维护者
- 创建新 Issue 说明情况

#### 方式二：私密报告（推荐，适用于敏感情况）

通过以下方式私密联系项目维护者：
- GitHub 私信
- 通过维护者的 GitHub 个人页面联系

#### 报告应包含：

- 你的联系信息（如果需要后续跟进）
- 违规行为的描述
- 发生的时间和地点（Issue #、PR # 等）
- 相关的截图或链接（如果有）
- 任何其他有助于理解情况的信息

### 处理流程

1. **接收报告**
   - 维护者在 48 小时内确认收到报告
   - 评估报告的严重程度

2. **调查**
   - 审查相关内容和上下文
   - 必要时联系相关方了解情况
   - 保护报告者的隐私

3. **决定措施**
   - 根据违规的性质和严重程度决定措施
   - 与其他维护者讨论（如果需要）

4. **执行和通知**
   - 执行决定的措施
   - 通知相关方（视情况而定）

### 可能的措施

根据违规的严重程度，维护者可能采取以下措施：

#### 1. 提醒（轻微违规）
- 私下或公开提醒
- 解释为什么行为不当
- 给予改正的机会

#### 2. 警告（中等违规）
- 正式警告
- 要求道歉或修正
- 暂时限制参与

#### 3. 临时禁止（严重违规）
- 暂时禁止参与项目（1 周到 1 个月）
- 禁止期间的所有互动

#### 4. 永久禁止（极其严重或重复违规）
- 永久禁止参与项目
- 所有贡献和互动特权被撤销

### 申诉

如果你认为对你的处理不公平：

1. 在收到通知后 14 天内提出申诉
2. 提供新信息或解释
3. 由未参与原始决定的维护者审查
4. 审查结果为最终决定

## 特殊考虑

### 隐私和数据保护

在 BetterBUCT 社区中：

- **不要**在公开场合分享他人的学号、密码或校园数据
- **不要**在 Issue、PR 或讨论中贴出包含敏感信息的截图
- **不要**未经许可使用他人的账号或数据进行测试
- 提交示例或日志前**必须**脱敏

违反隐私规定将被视为严重违规。

### 安全问题

- 安全漏洞应通过私密渠道报告（见 [SECURITY.md](SECURITY.md)）
- 不要公开披露未修复的安全问题
- 不要恶意利用安全漏洞

### 学术诚信

- 不要将 BetterBUCT 用于作弊或违反学校规定
- 不要提交或讨论自动答题、考试作弊等功能
- 尊重学校的教学和考试制度
